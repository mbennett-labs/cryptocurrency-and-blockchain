A dated research library covering cryptocurrency, blockchain infrastructure, decentralized finance (DeFi), token economics, airdrops, ecosystem developments, and investment risk.

The purpose is to preserve evidence-based research, distinguish confirmed developments from speculation, and provide a searchable reference for future analysis.

## Research principles

- Prefer primary documentation, on-chain evidence, published tokenomics, audits and clearly identified independent sources.
- Date all snapshots. Prices, token unlock schedules, rewards and contracts may change after publication.
- Label unofficial airdrop probabilities, forecasts and investment scenarios as estimates, not facts.
- Evaluate bridge, contract, liquidity, token distribution, governance and operational risks.
- Never commit wallet seeds, private keys, API credentials or private financial information.

## Formats

Reports are archived in their original **Markdown (.md)** and **PDF (.pdf)** forms, with a project-specific README for context. Markdown is the most suitable format for searching, updating, and AI-assisted analysis.
